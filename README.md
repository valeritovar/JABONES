## 🌟 Descripción
Sitio web profesional y responsive para la marca CLAUVITAE, especializada en jabones artesanales zodiacales.

## 📁 Estructura de Archivos

```
JABONES/
├── index.html          # Página principal
├── styles.css          # Estilos CSS
├── script.js           # Funcionalidad JavaScript
├── README.md           # Este archivo
└── images/             # Carpeta de imágenes
    ├── logo.png        # Logo de la marca (REEMPLAZAR)
    ├── favicon.png     # Favicon (REEMPLAZAR)
    └── favicon.ico     # Favicon alternativo
```

## 🚀 Instrucciones para Subir a Hostinger

### 1. Preparación
- **REEMPLAZAR IMÁGENES**: Sube tu logo real en:
  - `images/logo.png` (logo principal)
  - `images/favicon.png` (32x32px para favicon)
  - `images/favicon.ico` (formato .ico para compatibilidad)

### 2. Subida a Hostinger
- **Método 1 - FTP**: Sube todos los archivos a la carpeta `public_html`
- **Método 2 - File Manager**: Usa el administrador de archivos de Hostinger
- **Método 3 - Git**: Si tienes acceso Git, clona el repositorio

### 3. Archivos Obligatorios
✅ `index.html` - Página principal  
✅ `styles.css` - Estilos  
✅ `script.js` - Funcionalidad  
✅ `images/` - Carpeta de imágenes  
✅ `images/logo.png` - Logo (debe ser reemplazado)  
✅ `images/favicon.png` - Favicon (debe ser reemplazado)  

### 4. Configuración de Hostinger
- **Dominio**: Configura tu dominio apuntando a la carpeta donde subiste los archivos
- **SSL**: Activa HTTPS (generalmente incluido en Hostinger)
- **PHP**: No requerido (sitio estático HTML/CSS/JS)

## 🚨 Solución de Problemas

### Si el sitio no carga:
1. Verifica que todos los archivos estén en la carpeta correcta
2. Confirma que `index.html` sea el archivo principal
3. Revisa los permisos de archivos (generalmente 644 para archivos, 755 para carpetas)

### Si las imágenes no aparecen:
1. Verifica que los nombres de archivo coincidan exactamente
2. Confirma que la carpeta `images/` esté subida
3. Revisa las mayúsculas/minúsculas en los nombres

### Si WhatsApp no funciona:
1. Verifica el número 3112617515 en el código
2. Confirma que los enlaces usen `https://wa.me/`
